
# **Simple Web Application using Spring Boot**

##  Overview

This is a simple web-based application developed using **Spring Boot** for the backend and **HTML, CSS, and JavaScript** for the frontend. The project demonstrates the basic structure of a full-stack application and focuses on understanding core backend concepts.

---

##  Features

* Perform basic **CRUD operations** (Create, Read, Update, Delete)
* Implemented **REST API endpoints** using Spring Boot
* Structured application using **Controller, Service, and Repository layers**
* Handles HTTP methods: **GET, POST, PUT, DELETE**
* Simple frontend integration with backend APIs

---

##  Technologies Used

* Java
* Spring Boot
* Spring Data JPA
*  H2 (Database)
* HTML, CSS, JavaScript

---

##  Project Structure

* **Controller Layer** – Handles incoming HTTP requests
* **Service Layer** – Contains business logic
* **Repository Layer** – Manages database operations

---

##  API Methods Used

* **GET** – Retrieve data
* **POST** – Add new data
* **PUT** – Update existing data
* **DELETE** – Remove data

---

##  Learning Outcomes

* Understanding of Spring Boot project structure
* Hands-on experience with REST API development
* Knowledge of layered architecture (Controller-Service-Repository)
* Integration of frontend with backend APIs

---

##  How to Run

1. Clone the repository
2. Open in your IDE (IntelliJ / VS Code / Eclipse)
3. Run the Spring Boot application
4. Access the application in browser (e.g., `http://localhost:8080`)

---

##  Note

This project is created for learning purposes to understand the fundamentals of Spring Boot and full-stack development.
